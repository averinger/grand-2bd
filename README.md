# TikSave — скачивание видео TikTok без водяных знаков

Одностраничный сайт на чистом HTML/CSS/JS для хостинга на GitHub Pages. Пользователь вставляет ссылку на видео TikTok, сайт пытается извлечь прямую ссылку на видеофайл без водяного знака и предлагает его скачать.

## Структура

```
index.html        # главная страница
css/style.css     # стили (тёмная тема, стекло-морфизм, адаптив)
js/app.js         # клиентская логика (валидация, парсинг, скачивание)
README.md         # этот файл
```

## Как запустить локально

Просто откройте `index.html` в браузере. Сервер не требуется — весь код работает в браузере.

## Развёртывание на GitHub Pages

1. Создайте репозиторий на GitHub (например `tiktok-downloader`).
2. Загрузите в него файлы из этой папки:
   ```bash
   git init
   git add .
   git commit -m "Initial release: TikSave TikTok downloader"
   git branch -M main
   git remote add origin https://github.com/<ваш-username>/<репозиторий>.git
   git push -u origin main
   ```
3. Зайдите в настройки репозитория → **Pages**.
4. Источник: ветка `main`, папка `/ (root)`.
5. Нажмите **Save**. Сайт будет доступен по адресу `https://<ваш-username>.github.io/<репозиторий>/`.

## Как это работает (клиентская часть)

- Сайт валидирует, что введённая ссылка ведёт на TikTok.
- Последовательно перебирает несколько публичных CORS-прокси (`corsproxy.io`, `allorigins.win`, `cors.bridged.cc`, `corsfix.com`, `cors.x2u.in`), пока один не вернёт HTML страницы видео.
- Из HTML страницы извлекает прямую ссылку на видеоролик (`playAddr` / `downloadAddr`).
- Показывает видео в проигрывателе и кнопку «Скачать».

> **Важно:** GitHub Pages — статический хостинг, бэкенда нет. Публичные прокси могут работать нестабильно. Если все прокси недоступны, подключите свой бэкенд API или замените список `CORS_PROXIES` в `js/app.js`.

## Список прокси (в `js/app.js`)

| Прокси | Формат URL |
|--------|-----------|
| corsproxy.io | `https://corsproxy.io/?url=<цель>` |
| allorigins.win | `https://api.allorigins.win/raw?url=<цель>` |
| cors.bridged.cc | `https://cors.bridged.cc/<цель>` |
| corsfix.com | `https://corsfix.com/?url=<цель>` |
| cors.x2u.in | `https://cors.x2u.in/?url=<цель>` |

Если какой-то прокси перестанет работать, просто удалите его из массива `CORS_PROXIES` или добавьте новый в начало списка.

## Возможные проблемы

- **CORS:** публичные прокси имеют лимиты запросов и могут блокировать TikTok. Если все пять прокси недоступны, нужен свой бэкенд.
- **Приватные видео:** скачивание приватных или удалённых видео невозможно.
- **ТикТок может блокировать запросы** без правильных заголовков — в коде установлен `User-Agent` браузера.
- **Приватные видео:** скачивание приватных или удалённых видео невозможно.
- **ТикТок может блокировать запросы** без правильных заголовков — в коде уже установлен обычный `User-Agent`.
